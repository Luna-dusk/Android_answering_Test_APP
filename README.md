 **项目介绍**：说明“嵌入式刷题”是一款离线 Android 单选题练习应用。
 
 **主要功能**：介绍随机和专题练习、限时测验、错题本、收藏、草稿恢复、成绩分析、JSON 导入和成绩导出。
 
 **题库内容**：说明内置 72 道题，分为六个专题，每类 12 道。
 
 **开发环境与运行**：列出 Java 17、Android SDK 35、Gradle 8.11.1，以及使用 Android Studio 打开工程和运行的步骤。
 
 **项目结构**：简要介绍 `MainActivity`、`Question`、`QuizEngine` 和 `Store` 的职责。
 
 **题库导入**：说明 JSON 示例文件、必填字段、答案从 0 开始，以及单次导入数量和文件大小限制。
 
 **测试与限制**：说明计分规则检查，以及应用目前只支持本地数据和单选题。设备数据库检查会清除测试设备上的应用数据，应只在专用测试设备运行。
